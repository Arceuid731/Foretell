# Foretell

Foretell is an experimental adaptive encounter-intelligence plugin for FFXIV, built on BossMod Reborn.

V1 keeps the existing BMR stack available while adding local observation, mechanic-shape inference, confidence scoring, timeline learning, persistent encounter memory, replay/debug data, and predictive 3D/radar/text guidance.

## Dalamud custom repository

`https://raw.githubusercontent.com/Arceuid731/Foretell/main/repo.json`

## Safety model

Foretell is advisory by default. It does not add autonomous character movement. Low-confidence predictions are suppressed, especially for potentially lethal guidance. Learning data remains local.
